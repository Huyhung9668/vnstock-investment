# VNSTOCK INVESTMENT

Workspace thực hành dự án VNSTOCK × VIBE CODING × AGENT SKILLS trong VS Code với Codex.

## Mục tiêu
- Xây dựng một agent duy nhất hỗ trợ phân tích đầu tư
- Dùng Vnstock để lấy dữ liệu thị trường và doanh nghiệp
- Chuyển dữ liệu thành insight và báo cáo
- Xuất kết quả ra file markdown/html/pdf

## Cấu trúc thư mục
- data/: dữ liệu đầu vào và dữ liệu xử lý
- reports/: báo cáo đầu ra
- scripts/: script Python
- docs/: tài liệu nội bộ dự án
- tests/: kiểm thử
- .agents/skills/: skill và rule cho agent
