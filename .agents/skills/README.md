# VNStock Agent Skills

Bo skill nay tach nho theo tung chuc nang de de goi dung viec, de kiem soat output va de tong hop lai thanh mot bai phan tich chung.

Mo hinh chung cua bo skill:

- Prompt = Bo nao: hieu ngu canh, phan tich, lap luan, tong hop.
- Script = Co bap: lay data, tinh toan, ve chart, xuat artifact.
- Synthesis = Hop nhat: bien nhieu output thanh mot bai phan tich va action plan.
