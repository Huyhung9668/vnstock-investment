# Report Extractor

## Muc tieu

Lay thong tin co cau truc tu tai lieu phan tich va bao cao.

## Thuc hien

- Xac dinh loai file va dinh dang.
- Trich section quan trong: doanh thu, loi nhuan, no vay, guidance, rui ro, catalyst.
- Danh dau cau nao la fact, cau nao la nhan dinh.
- Bao luu link nguon hoac ten tai lieu neu co.

## Dau ra

- Structured notes theo tai lieu.
- Summary cac chi so va quan diem chinh.
- Input gon gon cho `60-market-analyst`.
