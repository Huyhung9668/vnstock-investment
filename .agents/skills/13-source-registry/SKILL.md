# Source Registry

## Muc tieu

Quan ly nguon du lieu mot cach minh bach va co kha nang audit.

## Thuc hien

- Liet ke cac source cho market, news, financials, reports.
- Gan muc uu tien, fallback, freshness, trust level.
- Ghi ro source nao chi dung cho enrichment, source nao la required.

## Dau ra

- Bang source registry.
- Ly do chon source.
- Input cho `22-data-guardian` va `11-vnstock-solution-architect`.
